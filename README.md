# Задача 4. Оптимизация рекламной нагрузки для платформы видеоконтента

Самостоятельная воспроизводимая экономическая модель платформы «ВидеоСервис». Все числовые вводные находятся в `data/task_04_ad_load_config.json`.

## Запуск

```bash
python -m pip install -r requirements.txt
jupyter notebook
```

Открыть `notebooks/task_04_ad_load.ipynb` и выполнить ячейки сверху вниз. Notebook рассчитывает денежные потоки, NPV, консервативный NPV с упущенным LTV, чувствительность к CPM и оттоку, сегментированные рекомендации и KPI-мониторинг.

## Важное методологическое решение

Основной NPV строится на фактическом месячном cash flow: рекламная выручка плюс подписная выручка минус CAC для замещения ушедших пользователей. Упущенный LTV показывается отдельно как долгосрочный риск. Такое разделение не смешивает текущие денежные расходы с будущей потерей дохода и не допускает двойного счёта.


## Расширение по когортным данным

В JSON есть блок `cohort_model`. В него можно загрузить фактические ряды времени просмотра, CTR, конверсии в платную подписку и ARPU для каждого уровня нагрузки. Notebook отдельно рассчитает когортные клики, платных пользователей, подписную выручку, cash flow и NPV.
