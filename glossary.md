# Глоссарий

| Термин | Определение |
|---|---|
| Рекламная нагрузка | Среднее число рекламных показов на пользователя в день. |
| CPM | Стоимость одной тысячи рекламных показов. |
| ARPU | Средний доход от одного пользователя за месяц. |
| Churn | Доля пользователей, ушедших из сервиса за рассматриваемый период. |
| CAC | Стоимость привлечения или замещения одного пользователя. |
| Cash flow | Текущий денежный поток за месяц. |
| LTV | Доход от пользователя за весь срок жизни. |
| NPV | Дисконтированная стоимость будущих денежных потоков за вычетом первоначальных инвестиций. |
| Консервативный NPV | NPV, дополнительно учитывающий оценённый упущенный LTV как долгосрочный риск. |
